 Advanced Expense Tracker

A modern **Salesforce Lightning Web Component (LWC)** based Expense Tracker application that helps users manage their daily expenses, monitor budgets, and visualize spending patterns through an intuitive and responsive interface.
 🚀 Features
- 📊 Interactive Dashboard
- 💸 Add, Edit, and Delete Expenses
- 📅 Expense Tracking by Date
- 🏷️ Category-wise Expense Management
- 📈 Budget Monitoring
- 📉 Spending Summary
- 📱 Responsive UI
- ⚡ Built with Salesforce Lightning Web Components (LWC)
- Add the bill for proofs add an image of an bill to remember

 🛠️ Technologies Used
- Salesforce Platform
- Lightning Web Components (LWC)
- Apex
- HTML
- CSS
- JavaScript
- Salesforce DX

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/iamdisha03/AdvancedExpenseTracker.git
```

Open the project in VS Code.

Authorize your Salesforce Org.

Deploy the source:

```bash
sf project deploy start
```

Run the application from your Salesforce Org.
